# API contract

## Resources and operations

For each operation, document method, path or procedure, purpose, and caller.

## Authentication and authorization

State identity requirements, permission checks, and tenant or ownership rules.

## Requests and responses

Document typed request fields, validation, response fields, status codes, and
examples that contain no sensitive data.

## Errors

List stable error codes, HTTP status mappings, safe messages, and client action.

## Compatibility

Describe versioning, pagination, idempotency, deprecation, and rollout impact.

## Handoff

**Changed contract:** Identify new, changed, or removed public behavior.

**Files / systems affected:** List consumers, services, and documentation.

**Evidence and tests:** List contract and integration checks.

**Risks / rollback:** State compatibility risks and the recovery path.

**What the next agent needs:** List implementation decisions and open questions.
