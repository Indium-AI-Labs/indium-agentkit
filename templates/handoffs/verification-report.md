# Verification report

## Scope

State the change, environment, revision, and explicit verification target.

## Commands and results

| Command | Result | Notes |
| --- | --- | --- |
| `command here` | pass, fail, or not run | Include relevant output summary. |

## Evidence

Link tests, screenshots, logs, metrics, or manual steps that demonstrate the
claimed behavior. Do not include credentials or sensitive payloads.

## Limitations

State checks that could not run, assumptions, flaky behavior, and remaining
uncertainty.

## Handoff

**Changed contract:** Summarize observable behavior or state `none`.

**Files / systems affected:** List touched components, services, and data.

**Evidence and tests:** List completed checks and their outcome.

**Risks / rollback:** State known risks and the recovery path.

**What the next agent needs:** List blockers, deployment notes, and follow-up.
